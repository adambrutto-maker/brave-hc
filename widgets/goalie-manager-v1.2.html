Publishing a goaltender confirmation

Click Prepare assignment beside a game. Its game key is copied and the authenticated GitHub Save Workflow ↗ opens. In GitHub, choose Run workflow, paste the game key, select that goalie, set dry_run = false and run. Confirm the workflow reports success. Repository write access is required.

This page is a manager aid, not an authenticated editor by itself. It does not save changes when a dropdown is selected. A GitHub commit is the confirmation receipt.
