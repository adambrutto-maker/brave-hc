Publishing a goaltender confirmation

Choose a goalie and click Review and confirm. GitHub opens a ready-to-submit issue containing the selected game and goalie. Review the details and click Submit new issue. The automation checks your GitHub repository write permission, confirms the game details and previously saved goalie are unchanged, and commits the assignment if needed, and closes the request with a receipt. Advanced GitHub workflow (manual signature + prior goalie required) ↗.

A dropdown choice alone does not save anything. GitHub requires a signed-in repository editor to submit the confirmation; others cannot authorize writes. If a request fails validation, its GitHub issue stays open with a reason and fresh-review instructions. If publishing fails, verify the saved goalie before trying again. Issue requests and outcomes are public repository records. Never enter passwords or tokens here.
