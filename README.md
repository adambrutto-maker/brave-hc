## Standing HockeyOS engineering requirements

Before changing the Player Bio, league-normalization settings, statistics, Records or Awards, read [AGENTS.md](AGENTS.md) and the [October 28 Bio normalization product contract](docs/261028_HockeyOS_Bio_Normalization_Product_Contract.md). The reusable source-gated conversion engine is [player-performance-normalization.js](widgets/player-performance-normalization.js); verified reference settings are [league-game-formats.json](widgets/league-game-formats.json). Run `node --test tests/test_player_performance_normalization.cjs` before review. The 18-source-season game-duration crosswalk is verified and the premium Bio was deployed to GitHub Pages and verified in official HTO profile tabs on 2026-10-28 (release PR #155, merge 248be3d001c104b28842451696bbe4385b0b104e). The new Bio uses actual G/A bars with an adjustable game-duration Pts/GP line and a native view of the existing provisional skater model. Goalie projections remain held pending a verified source adapter. The Bio presentation is live; the existing official HTO statistics/records/awards and original Master Workbook remain unchanged. Advanced numerical goalie forecasting, opponent-adjusted model coefficients and game-specific private coaching are not yet released. See docs/261028_HockeyOS_Player_Bio_Live_Release_Acceptance.md and issue #156 for unfinished work.
